# E-commerce Store Prebuilt Templates

A collection of  prebuilt e-commerce store templates, organized for developers.

## Structure

- \	emplates/\ — one folder per template, each with its own \README.md\ and \screenshot.png\
- \rchives/\ — original source archives (gitignored)
- \index.html\ — browsable gallery of all templates

## Getting started

1. Open \index.html\ in a browser to browse templates.
2. Open any \	emplates/<name>/\ folder to customize.
3. Replace placeholder images and copy with your own content.
4. Deploy to your hosting platform.
